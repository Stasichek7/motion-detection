# Motion Detection

## Overview
This project demonstrates a basic motion detection system using Python, NumPy, and Matplotlib. It detects changes between a background image and a current frame by calculating the absolute difference between them.

## Features
- Generates a synthetic background image.
- Simulates a frame containing a moving object.
- Adds random noise to simulate real-world conditions.
- Calculates the absolute difference between the background and current frame.
- Applies a threshold to detect motion.
- Visualizes the results using Matplotlib.

## Requirements
- Python 3
- NumPy
- Matplotlib
